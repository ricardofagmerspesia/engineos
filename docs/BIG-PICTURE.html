The system in one picture

Six layers. Prose at the top decides what should happen; data in the middle makes it deterministic; hooks and scripts at the bottom enforce it at runtime.

Reading the picture. A rule says "cap concurrency at ~6"; the number lives in registries/policy.json; kernel.sh admit reads it; rules/parallelism.md tells the orchestrator to ask the kernel before dispatching. Prose, data, decision, enforcement: one fact, four homes, one owner each.

Request lifecycle

What happens between "you type a request" and "done".

  • Classification precedes writing. The [router] line and the risk tier come before the first edit, never after.
  • Verification happens once. No per-edit test runs; the final gate is the single verification point, and the Stop hooks only check that it ran.
  • Every change leaves a record. mark-unrecorded.sh raises a flag on the first edit; record-verify.sh refuses "done" until record-change clears it.
  • Bypass is loud. The reply opens with [engineos] bypassed so nobody mistakes an unguarded session for a guarded one.

owner rules/risk-autonomy.md · rules/gates.md · registries/policy.json

Risk, autonomy, gates

Every other ceremony is proportional to the risk tier. Classify first; the tier decides how far you may go alone and which gates apply.

Gate ladder: Discovery → Design → Implementation → Validation → Release. The Stop hooks are the Validation gate. They know nothing about owners or rollback, so a green Stop is never the Release gate.

owner rules/parallelism.md · templates/handoff.md

Fan-out: waves, contracts, barriers

Parallel is the default past more than 3 files, more than 1 domain, or 3 or more independent tasks.

Hard rules: no two agents write the same file; the agent graph is flat, one level deep; a failed unit blocks its wave's barrier; BLOCKED and FAILED are real answers, never hidden by a green summary.

owner agents/*.md · registries/agents.json · rules/models.md

Agent roster by role

Model tiers: spec and PRD → most capable (fable); design, security, adversarial review → design (opus); code against a spec → build (opus); mechanical → cheap (haiku). The tier is the contract; the model name is today's binding.

the ten words that carry the system

Glossary

Router
The intent table in CLAUDE.md plus kernel.sh resolve-task; decides what to load and who to dispatch.
Task contract
The one block prompt-advisor.sh injects per prompt: intents, rules, agents, risk floor, gates.
Risk tier
low / medium / high, classified before the first write; everything else is proportional to it.
Autonomy ceiling
A0 to A4; how far you may go without a human, given the tier.
Gate
Discovery / Design / Implementation / Validation / Release, each with its mechanism and honest strength.
Final gate
Lint and typecheck run once at the end, tests only when ON; the Validation gate.
Change record
.engineos/changes/<date>-<slug>.md; opened on first edit, closed by record-change, archived.
Wave
One message of parallel agents over disjoint file scopes, ended by a barrier.
Kernel
scripts/kernel.sh; turns registry data into decisions so no caller reads policy directly.
Bypass
/engineos:bypass; turns every guardrail off, loudly, until the next session or toggled back.
