# Frozen contracts

1. Display `[agent][alias][role] | model: <actual configured model>` on startup, task/status, return and failure. Use registered aliases; worker-instance suffix is a separate field. Unknown alias falls back to canonical name; unavailable model is `inherited (exact model unknown)`. Short display role maps backend-coordinator→backend, frontend-coordinator→frontend, test-writer/qa-tester→qa, dba-coordinator→dba, security-reviewer→security, docs-writer→docs. Canonical role remains explicit on startup. Hook event envelope and telemetry remain unchanged.
2. All user decisions use permitted clickable input. Free-text needed? Offer clear choice to provide details plus text input. Choose specific checks triggers clickable check-by-check selection (Run / Skip; batch within tool limits), explicit final confirmation naming exact chosen commands; never execute unsubmitted defaults. Test-writing and execution remain final-only. No dependency installs. Hosts without controls must visibly explain text fallback.
3. Deep injection review traces untrusted input to executable/instruction sinks including SQL/NoSQL/search DSL, shell/code/template/HTML/path, prompt/retrieval/tool instructions and workflow files. List verified findings, related occurrences, mitigation, remediation owner and residual/unreviewed scope. Review stays read-only. Workers remove confirmed vulnerable paths across approved scope, not blanket deletion of fixtures or legitimate quoted source. External scope/DB changes require their own authorization. No claim of universal absence.
4. Database rule governs agent development/maintenance operations, including direct SQL, ORM/admin tools, data fixes, seed/backfill/schema sync/reset; ordinary authorized application operations unaffected. Default author migrations, never execute them automatically. Direct writes require actual explicit scoped confirmation naming DB/environment, operations/affected rows, rollback and exact command; generic implementation/testing permission insufficient. Read-only inspection permitted only with read-only credentials/operations; unknown or mixed statements denied. Isolated disposable test databases may be created/mutated only within an explicitly approved test command and never shared/live targets.

User steering: remove the :: punctuation from alias tags. Purple styling for the short role is optional only on hosts with verified inline color/badge support; plain Markdown/diff keeps the readable literal role without fake ANSI/HTML tokens.
