This published path remains during the compatibility window described in
`docs/COMPATIBILITY.md`. It no longer provides active FastAPI/Python guidance.

`rules/architecture.md`, `rules/backend.md`, `rules/observability.md`,
`rules/testing.md` and `nestjs-patterns`. Explain unsupported legacy requests
and obtain an ecosystem-compatible scope; do not silently translate a project.
