# Build and integrate

Read approved plan.md and acceptance claims in checks.md. Assign dependency-ready
slices exclusive file scopes and frozen contracts under rules/parallelism.md.
Implementation workers author no tests and run no intermediate validation gates.
They return diff evidence and remaining dependencies. The orchestrator integrates
continuously, then performs one final non-test lint/typecheck/build stage.
Commit authorization follows rules/git.md, never the spec alone.
