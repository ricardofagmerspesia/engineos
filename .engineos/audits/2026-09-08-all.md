# EngineOS self-audit — STATUS: CRITICAL

Five read-only auditors over disjoint scopes (kernel/checks/journal; hooks/install/CI security; CI/packaging/release; prose layer and docs; console/). All five returned confirmed defects. Six HIGH findings survive deduplication. Nothing below was downgraded on review.

## Root causes

1. **Prose claims with no mirror check.** "62-check validator" (real: 104) in 9 sites, "nine hooks" (8 registered), `/analisy-architecture` (renamed, no COMPATIBILITY entry), AGENTS.md still on the jq era. Five headline claims have no checker. Explains every documentation finding.
2. **Bash-era artifacts kept alive after the TypeScript port.** `scripts/checks/*.sh` (C32–C35) unregistered; `commands/route.md` reintroduces jq; `templates/adapters/*` describe pre-1.7.0 wiring; `package-release.sh` allowlists `hooks/lib-*.sh` (gone) and ships the dead checks; CI lints `scripts/*.sh` non-recursively.
3. **The package job asserts the dev suite instead of artifact properties.** `npm test` inside the tarball fails 24 (fixtures and `.engineos/archived/**` do not ship), so the gate is permanently red on main and on #70. That hid the `install.sh` `node_modules` scan abort, and the exec-bit (`[ -x ]` on MSYS) and CRLF (`grep -U` post-extract) checks answer for reasons unrelated to the artifact.
4. **Containment checked at one edge, not at every consumer.** Stop-gate consent is verified on `repoRoot(cwd)` while `findUpAny` walks to `/`; `loadRouting`/`loadIntents` coerce where five sibling loaders throw; console's write path joins `REPO_ROOT` without asserting the result stays under it; the installer unions `permissions.allow` with no diff.
5. **`console/` built on trust assumptions never expressed in code.** "Local single-operator tool" is a design note, not a control: no middleware, no origin check, `as SkillPatch` instead of a schema, frontmatter semantics duplicated from the kernel rather than shared, so the two disagree on `enabled: "false"` and indented keys.

## Findings, ranked by impact

### (a) Security reachable by a third party or a hostile repo

- **[HIGH] Stop gate runs `npm run lint|typecheck` from any ancestor of any edited path, outside the adopted repo.** `src/hooks/stop-verify.ts:93` checks `.engineos/` on `repoRoot(cwd)` only; `:107,187-194` and `src/hooks/verify-targets.ts:43-54` walk every edited `file_path` up to `/`. `/private/tmp` is mode 1777: any local process plants a `package.json` with a `lint` script and the next session that edits a scratchpad `.ts` executes it. Reproduced (PoC wrote a marker file). Fix: every candidate package dir must equal `root` or sit under `root + '/'`; stop `findUpAny` at root.
- **[HIGH] `POST /api/publish` and `POST /api/rollback/:id` commit or revert the repo with no auth, no origin check, no body.** `console/src/app/api/publish/route.ts:34`, `rollback/[historyId]/route.ts:27`; no `middleware.ts`. Bodyless simple POST, no preflight: any page the operator visits while `next dev` runs can rewrite the repo. `next dev` binds `0.0.0.0` by default (plausible, not booted). Fix: same-origin middleware on `Sec-Fetch-Site`/`Origin`; `-H 127.0.0.1` in dev/start scripts.
- **[MEDIUM] `announce-agent-return` banner unbounded.** `src/hooks/announce-agent-return.ts:19` bypasses `bannerField`; the dispatch-side fix from 567d0db landed on one of two hooks. `"` also unstripped by `BANNER_UNSAFE`.
- **[MEDIUM] Installer silently widens `~/.claude/settings.json` `permissions.allow` for all projects.** `install.sh:269-272`, `install.ps1:304-309`, `src/install/settings-merge.ts:179-199`. `Bash(grep:*)`, `Bash(jq:*)` become unprompted arbitrary-file-read; `allow` outranks a user's `ask`. Fix: print entries, require confirmation, ship template opt-in.
- **[MEDIUM] `live-evals.yml:26-34` installs `@anthropic-ai/claude-code` unpinned, postinstall on, in the job that then exports `ANTHROPIC_API_KEY`.** Fix: pin exact version, `--ignore-scripts`, or scope the key.
- **[MEDIUM] `console/src/app/api/effective/route.ts:31` spawns `bash scripts/kernel.sh` with uncapped `?path=`/`?prompt=`, no UI consumer; write path lacks a `REPO_ROOT` containment assert** (`entities/skills.ts:224`, `publish/route.ts:117`).

### (c) CI and release

- **[HIGH] `package` job runs the dev suite inside the artifact.** `.github/workflows/ci.yml:199` `npm test`; job 102100477504 `# fail 24` (ENOENT on `test/fixtures/legacy-journal/exec-journal.sh`, `.engineos/archived/...`, no `.git`). Red on main and on #70.
- **[HIGH] `install.sh` aborts on the release zip once dependencies are installed.** `install.sh:31-33` non-git fallback scans `node_modules/@types/node/url.d.ts` (a JSDoc example URL carrying `user:pass@host` credentials). This is the documented zip install path and the abort behind the red job. Fix: `--exclude-dir=node_modules --exclude-dir=dist-release --exclude-dir=build --exclude-dir=.next`, plus the `install.ps1:60-67` equivalent.
- **[HIGH] Windows artifact checks are wrong by construction.** `scripts/package-release.sh:139-163` `[ -x ]` reads the shebang on MSYS, so the two shebang-bearing 100644 libs are flagged and the `noexec` half passes vacuously; the CRLF check (`:147`) tests the extractor, since `git archive` applies EOL conversion on Git for Windows. Fix: modes via `git ls-tree -r "$COMMIT"`; LF via `git ls-files --eol` or a node byte scan; `git -c core.autocrlf=false -c core.eol=lf archive`.
- **[MEDIUM]** `package` has no `needs: verify` and uploads regardless (`ci.yml:156,210`); no `concurrency`, no `timeout-minutes` anywhere; `npm audit --audit-level=high` blocks every unrelated PR (`ci.yml:36`); no tag or release automation (`git tag` is empty); dependabot covers `/` only, `console/` lockfile unscanned and `npm audit` never runs in the console job.
- **[LOW]** `Tools present` runs before `setup-node` (`ci.yml:19-25`); `scripts/*.sh` shellcheck glob is non-recursive and `-S error` hides warnings; `install.ps1` never linted or executed although `windows-latest` is in the matrix (`src/install/install-hooks.e2e.test.ts:21` claims "no PowerShell on CI", false); `package-release.sh:141` matches the removed `hooks/lib-*.sh`; `:93-97` checks `plugin.json` version but not `marketplace.json`; `ci.yml:201-208` idempotency step computes hashes and asserts nothing.
